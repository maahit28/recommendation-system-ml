## 🎬 Global Movie Recommendation System

A hybrid AI-based movie recommender that fetches real-time global movies 
from TMDB and recommends content based on:

- User intent (genre, region, type)
- Semantic similarity
- Popularity score

### Features
- Hollywood, Bollywood, Korean & Anime support  
- Movie & Series recommendations  
- Poster display  
- AI intent detection  
- Streamlit UI  

### Tech Stack
- Python
- Streamlit
- TMDB API
- NLP similarity
- Pandas
