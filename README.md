🎬 Global Movie Recommendation System
A smart, aesthetic, and AI-powered movie recommendation web app that suggests movies, series, and documentaries from across the world based on user preferences and natural language input.

✨ Features
🌍 Global recommendations (Hollywood, Bollywood, Korean, Anime)

🧠 AI-based intent detection (genre, region, content type)

🔍 Text similarity matching for better results

🎬 Live data from TMDB API

🖼️ Movie posters with clean UI

💖 Like / Save system

🎨 Aesthetic, modern interface

⚡ Fast and responsive

🛠️ Tech Stack
Python

Streamlit (Web UI)

TMDB API (Movie data)

Pandas

Scikit-learn

NLP / Text Similarity

🚀 How It Works
User enters what they want to watch

The system detects:

Genre

Region

Content type

Movies are fetched from TMDB

AI ranks them using similarity + popularity

Best recommendations are displayed with posters

▶️ How to Run Locally
bash
Copy code
git clone https://github.com/maahit28/recommendation-system-ml.git
cd recommendation-system-ml
pip install -r requirements.txt
streamlit run app.py
Make sure you add your TMDB API key in a .env file.
